# Monetos metimo (coin toss) assetai

Įdėk du PNG (permatomas fonas, kvadratiniai, rekomenduojama 512×512):

- `coin-green.png` — ŽALIA pusė: iškrenta, kai pradedi TU.
- `coin-red.png`  — RAUDONA pusė: iškrenta, kai pradeda PRIEŠININKAS.

Failų nesant, rodomas sintezuotas fallback'as (žalias/raudonas metalinis
diskas su ⚔). Failui atsiradus jis naudojamas automatiškai — kodo keisti
nereikia (file-first principas kaip su garsais).
